# onboarding

Remember the recruiter context before any search. Do not call Kalent from this skill.

https://docs.kalent.ai

## Remember

Ask for the company, the kind of roles they hire, the market, and the language of the verdicts (`fr` or `en`). Remember the answers.

## Level

Explain the two levels once. Do not explain them again later.

Plain search is the default. It returns profiles that pass the filters, and it is fast.

Qualified search has an AI judge each profile. It costs two credits per profile. Use it when a must-have does not fit in a filter.

Ask once which level to keep. If they do not choose, remember plain search.

Do not start a search.
