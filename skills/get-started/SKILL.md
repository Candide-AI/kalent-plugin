# get started

Sign in when the client opens Kalent’s OAuth screen. Leave API key fields empty. Auth is OAuth with PKCE and dynamic client registration.

https://docs.kalent.ai

Server URL: https://app.kalent.ai/api/mcp

Ask which role to fill, then use find-talent. Hand enrichment and sequences to reach-candidates.

Search, qualification, and enrichment use workspace credits. A sequence messages real people, so show the copy and wait for a yes.
